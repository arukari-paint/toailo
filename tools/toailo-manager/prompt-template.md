# 1. TOAILO のブランド方針

- ブランドメッセージ：「記録する。持ち出す。AIで活かす。」
- TOAILO は、日々の記録を ChatGPT・Claude・Gemini など利用者が選んだAIへ「持ち出して」活用するアプリシリーズです。
- **TOAILO のアプリは、アプリの中でAIを呼び出したり、記録をAIへ自動送信したりしません。** アプリはAIに渡しやすいテキストを作るだけで、利用者が自分でコピーしてAIに貼り付けます。記事中でこの仕組みを正確に説明してください。
- 合計・件数などの集計はアプリが計算してから渡し、AIには読み解きを任せる、という考え方です。
- データは端末に保存されます。AIに何を渡すかは利用者が選びます。
- お金の使い方や仕事の進め方の良し悪しを判定しません。AIの回答は参考情報として扱います。
- 金融商品・投資の助言、医療・心理の診断にあたる内容は書きません。
